# Library Management System

A console-based Library Management System developed in C++.

## Features

- Add books
- Display all books
- Search books by ID
- Borrow books
- Return books
- Delete books
- Automatic book ID generation
- Admin authentication for adding and deleting books
- Input validation
- Prevent deletion of borrowed books

## Technologies

- C++
- Object-Oriented Programming
- Arrays
- Classes and Objects
- Constructors
- Functions
- Input Validation

## How to Run

1. Clone the repository
2. Open the project in VS Code
3. Compile `main.cpp`
4. Run the executable
